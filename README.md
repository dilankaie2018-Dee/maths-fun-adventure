🌟 Maths is a Fun Adventure 🌟

“Count it, solve the sums, and become a Master in Mathematics!”

Welcome to Maths is a Fun Adventure, a colourful and interactive maths learning website designed to make learning addition enjoyable for young children.

🎯 About the Website

Maths is a Fun Adventure is an educational game for children aged 5–8 years old. Instead of traditional worksheets filled with numbers, children learn through colourful pictures, cute animals, and fun interactive challenges.

The website currently contains 50 addition questions, helping children develop their counting and basic addition skills while keeping them engaged.

✨ Features
🍓 Colourful fruit and animal illustrations
🧮 50 simple addition questions
🎮 Interactive game-style learning
⭐ Score tracking
🔥 Streak counter
📊 Progress bar
✅ Instant answer feedback
🏆 Final score and achievement message
🔄 Play-again option
📱 Responsive design for computers, tablets, and mobile devices
👧 Suitable for children around 5–8 years old
🧒 Learning Objectives

The website helps children practise:

Counting objects
Recognising quantities
Understanding addition
Solving simple addition problems
Developing confidence with mathematics
Learning through visual and interactive activities


🍎 How to Play
Look at the groups of fruits or cute objects.
Count how many are in each group.
Add the two groups together.
Enter your answer or choose an answer option.
Click “Check! ✨”
Continue through all 50 questions.
See your final score and become a Maths Master! 🏆
